# XGBoost 模型超参数说明

> 项目：CICIDS2017 入侵检测（可解释 AI 实时检测平台）
> 模型：XGBoost 多分类（8 类威胁：BENIGN / DDoS / PortScan / Botnet / BruteForce / WebAttack / DoS / Infiltration）
> 训练脚本：`src/train_ml.py`（二分类）、`src/train_ml_multi.py`（多分类）

下表列出模型训练使用的关键超参数及其选择理由。二分类与多分类任务使用同一套参数，仅 `eval_metric` 不同（`logloss` / `mlogloss`）。

| 参数名 | 取值 | 选择理由 |
|---|---|---|
| `n_estimators` | 300 | CICIDS2017 是 69 维手工设计流特征、信息密度高的表格数据，300 棵树在 24 万训练样本上已充分拟合（多分类 Weighted-F1 0.9989）。过少的树欠拟合，过多则拖慢推理；300 是精度与延迟的平衡点，且 XGBoost 内建 shrinkage（learning_rate）可缓解树数增加带来的过拟合。 |
| `max_depth` | 8 | 限制单棵树深度即限制模型复杂度，是防过拟合的核心手段。本项目类别失衡明显（Attack 仅占 16.9%，Infiltration 仅 1 条测试样本），深度过大容易对少数类样本过度拟合；深度过浅则无法捕捉特征间的交互。8 层在 XGBoost 社区属成熟偏保守的取值，配合正则项在精度与泛化间取得平衡。 |
| `learning_rate` | 0.1 | 步长控制每棵树对整体预测的贡献（shrinkage）。0.1 是该数据量下的常用默认：足够小以保证提升过程的稳健性，又不至于像 0.01 那样需要上千棵树才收敛。300 棵树 × 0.1 的组合对应成熟社区配置，实测二分类 F1=0.9974。 |
| `subsample` | 0.8 | 每轮迭代随机采样 80% 样本训练（行采样），引入随机性降低过拟合风险，是 XGBoost 内置的正则机制之一。CICIDS2017 样本量充足（去重后 250 万条、训练集 24 万条），80% 采样不会损失有效信息。 |
| `colsample_bytree` | 0.8 | 每棵树随机选取 80% 特征参与分裂（列采样）。69 维特征中存在相关性较强的组（如各方向包长、IAT 统计量），列采样迫使每棵树看到不同特征子集，减少对单一特征的依赖，增强鲁棒性并防过拟合。 |

> 补充：其余参数沿用默认——`tree_method="hist"`（直方图加速，适合中大规模数据与快速推理）、`n_jobs=-1`（并行）、`random_state=42`（保证实验可复现）、多分类时在 `fit` 中传入逆频 `sample_weight`（缓解类别失衡）。
